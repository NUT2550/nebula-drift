# 🚀 NEBULA DRIFT

> Vertical space shooter — สร้างด้วย workflow "สมองสั่ง · AI สร้าง"
> Directive #01: Core Prototype

🎮 **เล่นเลย:** https://NUT2550.github.io/nebula-drift/

## วิธีเล่น
| ปุ่ม | การกระทำ |
|---|---|
| WASD / ลูกศร | เคลื่อนที่ 8 ทิศทาง |
| SPACE | แดชหลบ (มี i-frame กันกระสุน) |
| X | บอมบ์ล้างจอ |
| Q / E / 1-3 | สลับอาวุธ (SPREAD / LASER / HOMING) |
| P · M | หยุดเกม · ปิด/เปิดเสียง |

ยานยิงอัตโนมัติ · เก็บ **P** อัปเกรดอาวุธ (Lv 1–3) · **S** เพิ่มโล่ · **B** เพิ่มบอมบ์
ยิงต่อเนื่องเพื่อสะสม Chain ตัวคูณสูงสุด **x8** · **บอสปรากฏทุกเวฟที่ 5**

## ฟีเจอร์
- 3 อาวุธ: Spread / Laser (ทะลุทะลวง) / Homing (ล็อกเป้า)
- ศัตรู 5 AI: Drone · Gunner · Weaver · Splitter · Sniper (มีเส้นเล็งเตือน)
- บอส 4 แพทเทิร์น + โหมดคลั่งเมื่อเลือดต่ำ
- Chain Score x8 · Best Score บันทึกอัตโนมัติ
- พิกเซลอาร์ต 9:16 · เสียงสังเคราะห์ WebAudio (ไฟล์เดียวจบ ไร้ dependency)

## เทคโนโลยี
HTML5 Canvas + Vanilla JavaScript
